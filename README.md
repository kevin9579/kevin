# 휴대폰 녹음 폴더 → 구글 드라이브 자동 업로드 설정 가이드

> **대상 기기:** 삼성 갤럭시 **S24+** (One UI 6 기준)
> **목표:** 휴대폰의 **전화(통화녹음) · 에이닷 전화 · 음성녹음** 폴더에 새 파일이 생기면 **자동으로 구글 드라이브에 업로드**되도록 설정
> **방식:** 코딩 없이, 무료 자동화 앱 **FolderSync** 사용 (앱 설치 → 구글 드라이브 연결 → 폴더 지정 → 자동 동기화)

이 문서는 [`docs/`](docs/) 폴더의 상세 자료와 함께 보세요.

- 📂 [폴더 경로 빠른 참조](docs/폴더경로.md)
- ❓ [문제 해결 / 자주 묻는 질문](docs/문제해결.md)
- 🔁 [대안 도구 (Autosync, MacroDroid)](docs/대안도구.md)

---

## 📌 한눈에 보기

```
[휴대폰 녹음 폴더]                          [구글 드라이브]
 /Recordings/Call               ─┐
 /Recordings/Voice              ─┼──(FolderSync 자동 동기화)──▶  /녹음백업/...
 /Recordings/TPhoneCallRecords  ─┘            (새 파일 생기면 자동 업로드)
```

S24+는 **세 폴더가 모두 내장 저장공간 `Recordings` 폴더 아래**에 있어서, 특별한 권한 없이 그대로 동기화할 수 있습니다. (안드로이드 `Android/data` 폴더 접근 제한과 무관)

---

## 1단계. 내 휴대폰의 녹음 폴더 위치 확인

먼저 **"내 파일"** 앱에서 폴더가 실제로 있는지 확인하세요. (`내 파일 > 내장 저장공간` 으로 이동)

| 종류 | 폴더 경로 (내장 저장공간 기준) |
|---|---|
| **전화 (삼성 통화녹음)** | `Recordings / Call` |
| **음성녹음 (삼성 음성 녹음기)** | `Recordings / Voice` |
| **에이닷 전화 (A. 통화녹음)** | `Recordings / TPhoneCallRecords` |

> 💡 **에이닷 폴더가 안 보이면?**
> 기기/앱 버전에 따라 `Music / TPhoneCallRecords` 또는 `mysounds` 폴더에 저장되기도 합니다.
> 에이닷 앱 안에서 **설정 > 통화 설정 > 통화녹음**으로 들어가면 녹음 파일 저장 위치를 직접 확인할 수 있습니다.
> 정확한 경로는 [docs/폴더경로.md](docs/폴더경로.md)에서 찾는 방법을 참고하세요.

✅ **TIP:** 세 폴더가 모두 `Recordings` 안에 있으므로, **`Recordings` 폴더 하나만 동기화**하면 세 가지가 한 번에 백업됩니다(아래 3단계 "간단 방법" 참고).

---

## 2단계. FolderSync 설치 & 구글 드라이브 연결

1. **Play 스토어**에서 **`FolderSync`** 검색 후 설치 (무료 버전으로 충분합니다)
2. FolderSync 실행 → 처음 뜨는 **권한 요청 모두 허용**
   - **모든 파일 접근(All files access)** 권한을 꼭 허용해야 녹음 폴더를 읽을 수 있습니다.
3. 왼쪽 메뉴(또는 하단) → **계정(Accounts)** → **계정 추가(Add account)**
4. 목록에서 **Google Drive** 선택 → **인증(Authenticate/Login)**
5. 업로드할 **구글 계정 선택** → 권한 **허용**
6. 계정 이름이 목록에 나타나면 연결 완료 ✅

---

## 3단계. 동기화 폴더쌍(Folderpair) 만들기

### ✅ 간단 방법 (추천) — 폴더 하나로 세 폴더 모두 백업

`Recordings` 폴더 전체를 동기화하면 Call · Voice · TPhoneCallRecords가 한 번에 올라갑니다.

1. FolderSync → **폴더쌍(Folderpairs)** → **+ (새로 만들기)**
2. 아래와 같이 설정:

| 항목 | 설정 값 |
|---|---|
| **이름(Name)** | `녹음 전체 백업` |
| **계정(Account)** | 2단계에서 추가한 Google Drive |
| **동기화 유형(Sync type)** | **로컬 → 원격 (To remote folder)** ← *업로드만* |
| **원격 폴더(Remote folder)** | 구글 드라이브 안에 `녹음백업` 폴더 새로 만들어 선택 |
| **로컬 폴더(Local folder)** | `내장 저장공간 / Recordings` 선택 |

3. **하위 폴더 포함(Sync subfolders)** = **켜기(ON)** 확인
4. 저장

> 이 방법이면 폴더쌍 **1개**만 만들면 됩니다.

---

### 🧩 분리 방법 — 폴더별로 따로 관리하고 싶을 때

폴더마다 구글 드라이브 위치를 다르게 두고 싶으면, 아래 표대로 **폴더쌍 3개**를 만드세요. (만드는 과정은 위와 동일, "로컬 폴더"와 "원격 폴더"만 다름)

| 폴더쌍 이름 | 로컬 폴더 (내장 저장공간) | 원격 폴더 (구글 드라이브) |
|---|---|---|
| `통화녹음 백업` | `Recordings / Call` | `녹음백업 / 전화` |
| `음성녹음 백업` | `Recordings / Voice` | `녹음백업 / 음성녹음` |
| `에이닷 백업` | `Recordings / TPhoneCallRecords` | `녹음백업 / 에이닷전화` |

세 개 모두 **동기화 유형 = 로컬 → 원격(업로드만)**, **하위 폴더 포함 = 켜기** 로 설정하세요.

---

## 4단계. 자동 동기화(실시간/예약) 설정

각 폴더쌍에서 **"동기화 옵션(Sync options)" / "스케줄(Scheduling)"** 항목을 엽니다.

### 방법 A — 실시간 자동 (파일 생기면 바로 업로드) ⭐추천
- **변경 시 동기화 / 즉시 동기화(Sync on file change / Instant sync)** = **켜기**
- 새 녹음 파일이 만들어지는 즉시 자동으로 올라갑니다.

### 방법 B — 예약 동기화 (일정 간격)
- **예약 동기화(Use scheduled sync)** = **켜기**
- **고급(Advanced)** 또는 **간격(Interval)** 에서 예: **매시간** 또는 **하루 1회(예: 새벽 3시)** 선택
- 데이터/배터리를 아끼고 싶으면 이 방법이 좋습니다.

### 공통 권장 옵션
- **Wi‑Fi에서만 동기화(Sync only over Wi‑Fi)** = 켜기 → 모바일 데이터 절약
- **충전 중에만(Only when charging)** = 선택 사항
- **원격에서 삭제 안 함** : 동기화 유형을 "로컬→원격(업로드만)"으로 두면 휴대폰에서 파일을 지워도 드라이브 백업은 유지됩니다. (양방향/미러링이 아님)

---

## 5단계. 배터리 최적화 예외 (백그라운드 유지)

자동 동기화가 멈추지 않게 하려면:

1. 휴대폰 **설정 > 배터리 > 백그라운드 사용 제한(앱 절전)** 으로 이동
2. **FolderSync**를 **"제한 없음 / 절전 안 함"** 으로 설정
3. (설정 > 애플리케이션 > FolderSync > 배터리 > **제한 없음** 도 동일)

이걸 안 하면 화면이 꺼져 있을 때 동기화가 지연되거나 누락될 수 있습니다.

---

## 6단계. 첫 동기화 테스트

1. 폴더쌍 목록에서 만든 항목의 **▶ (지금 동기화 / Sync now)** 버튼을 누릅니다.
2. 진행 상황 표시 후 완료되면, **구글 드라이브 앱**에서 `녹음백업` 폴더에 파일이 올라왔는지 확인합니다.
3. 실제로 **짧은 음성 녹음을 하나 만든 뒤** 잠시 기다렸다가, 자동으로 업로드되는지 확인하면 끝! 🎉

---

## ⚠️ 알아두면 좋은 점

- **업로드만(단방향):** 위 설정은 휴대폰 → 드라이브 **업로드 전용**입니다. 휴대폰 저장공간을 비워도 드라이브 백업은 그대로 남습니다.
- **에이닷 폴더 경로 변동:** 에이닷 앱 업데이트로 저장 위치가 바뀔 수 있습니다. 자동 업로드가 안 되면 [docs/폴더경로.md](docs/폴더경로.md)로 실제 경로를 다시 확인하세요.
- **통화녹음 법적 주의:** 본인이 포함된 통화 녹음은 한국에서 합법이지만, 녹음 파일을 제3자에게 공유·유포할 때는 주의가 필요합니다.
- **용량:** 구글 드라이브 무료 용량은 15GB(지메일/사진 공유)입니다. 녹음이 쌓이면 용량을 확인하세요.
