# 대안 도구

README의 FolderSync 방식이 가장 추천되지만, 취향/상황에 따라 아래 대안도 가능합니다.

---

## 1. Autosync for Google Drive (DriveSync) — MetaCtrl

구글 드라이브 전용 동기화 앱이라 연결이 가장 단순합니다.

- **장점:** 설정이 직관적, 구글 드라이브에 특화, 실시간 자동 업로드(Instant sync)
- **단점(무료 버전 제한):**
  - 동기화 **폴더쌍 1개**만 가능 → 세 폴더를 따로 하려면 유료(한 번 결제)
  - 파일 크기 제한(개당 약 10MB) — 긴 녹음은 잘릴 수 있음
- **세 폴더 한 번에 하려면:** 무료 버전에서는 상위 `Recordings` 폴더 하나만 폴더쌍으로 지정하면 Call/Voice/TPhoneCallRecords가 함께 올라갑니다(파일 크기 제한은 유의).

**설정 요약:** 설치 → 구글 계정 연결 → 동기화 폴더 = `Recordings` → 동기화 방식 = **Upload only** → 자동 동기화 켜기.

---

## 2. MacroDroid / Tasker (자동화 앱)

"새 녹음 파일 감지 → 구글 드라이브 업로드" 매크로를 직접 구성하는 방식입니다.

- **장점:** 세밀한 조건(특정 시간, 충전 중 등) 제어 가능
- **단점:** 구글 드라이브 직접 업로드 액션 구성이 까다롭고, 무료 버전 매크로 개수 제한(MacroDroid 5개) 등이 있어 **초보자에겐 비추천**
- 녹음 같은 "폴더 → 클라우드 백업" 용도로는 FolderSync/Autosync가 더 안정적입니다.

---

## 3. 구글 드라이브 앱 수동 백업 (자동 아님)

자동화 없이 가끔 직접 올리고 싶다면:
- "내 파일"에서 녹음 파일 선택 → **공유 > 드라이브에 저장**
- 또는 구글 드라이브 앱에서 **+ > 업로드**로 폴더 파일 선택
- 자동이 아니므로, 정기 백업에는 FolderSync를 권장합니다.

---

## 정리: 어떤 걸 고를까?

| 상황 | 추천 |
|---|---|
| 세 폴더 모두 무료로 자동 백업 | **FolderSync** (README 참고) ⭐ |
| 구글 드라이브 하나만, 가장 단순하게 | Autosync (단, 무료 1폴더·용량제한) |
| 복잡한 조건 제어를 직접 만들고 싶음 | MacroDroid/Tasker |
| 가끔 손으로 백업 | 구글 드라이브 앱 수동 업로드 |
