# 앱 설치 가이드 (두 개의 앱)

> ⚠️ 앱 설치는 **휴대폰에서 직접** 진행해야 합니다(가이드 작성자가 원격으로 설치할 수 없음).
> 아래 링크를 휴대폰에서 누르면 **Play 스토어 설치 화면**으로 바로 이동합니다.

---

## 1️⃣ FolderSync (백업용 — 폰 → 구글 드라이브 자동 업로드)

- **앱 이름:** FolderSync (무료 버전으로 충분)
- **Play 스토어 링크:**
  https://play.google.com/store/apps/details?id=dk.tacit.android.foldersync.lite
- **만든 곳:** Tacit Dynamics (다운로드 170만+, 검증된 앱)

### 설치 방법
1. 위 링크를 휴대폰에서 누르거나, Play 스토어에서 **`FolderSync`** 검색
2. **설치(Install)** 버튼 누르기
3. 설치 후 **열기(Open)** → 첫 실행 시 뜨는 권한 요청에서
   **모든 파일 접근(All files access)** 을 반드시 **허용**
4. 이후 설정은 [README.md](../README.md) 2~6단계로 진행

> 참고: 광고 제거/고급 기능이 필요하면 유료판 **FolderSync Pro**
> (`dk.tacit.android.foldersync.full`)도 있지만, 이 용도는 무료판으로 충분합니다.

---

## 2️⃣ Auto Folder Cleaner (정리용 — 오래된 폰 원본 자동삭제)

- **앱 이름:** Auto Folder Cleaner
- **Play 스토어 링크:**
  https://play.google.com/store/apps/details?id=com.radefffactory.autofoldercleaner
- **용도:** 폴더별/전체로 "N일 지난 파일 자동 삭제" → 폰 저장공간 확보

### 설치 방법
1. 위 링크를 휴대폰에서 누르거나, Play 스토어에서 **`Auto Folder Cleaner`** 검색
2. **설치(Install)** 버튼 누르기
3. 설치 후 **열기** → 파일 접근(저장공간) 권한 **허용**
4. ⚠️ **지금은 설정만 해두고, 삭제 주기는 나중에** — **백업(FolderSync)이
   드라이브에 잘 올라가는 걸 확인한 뒤에** 삭제 규칙을 켜세요.
5. 설정 방법은 [오래된원본_자동삭제.md](오래된원본_자동삭제.md) 참고

---

## ⚠️ 설치 후 공통 — 배터리 최적화 예외 (꼭!)

두 앱 모두 백그라운드에서 멈추지 않게 하려면:
1. 휴대폰 **설정 > 배터리 > 백그라운드 사용 제한(앱 절전)**
2. **FolderSync** 와 **Auto Folder Cleaner** 를 각각 **"제한 없음"** 으로 설정

---

## 설치 순서 권장
1. **FolderSync 먼저 설치 + 설정** → 드라이브에 잘 올라가는지 확인 ✅
2. 그게 확인된 **뒤에** Auto Folder Cleaner 설치 + 삭제주기 설정
