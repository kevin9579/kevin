# 오래된 폰 원본 자동삭제 (1개월·12개월 등 기간 지정)

> **요약:** 드라이브에는 영구 백업하고, 폰 원본은 "N개월 지난 것"부터 자동으로 지워
> 저장공간을 확보하는 구성. **FolderSync 자체에는 기간 지정 삭제 옵션이 없으므로**,
> "백업(FolderSync)" + "기간 기반 자동삭제(별도 도구)" 두 가지를 조합한다.

---

## 왜 조합이 필요한가

- **FolderSync "이동(Move files)" 옵션** = 업로드 직후 원본을 **즉시 삭제**(보관기간 0). → "1개월 뒤"처럼 기간 지정 불가.
- FolderSync / Autosync 모두 **"N일·N개월 지난 파일만 삭제"하는 나이(age) 기반 삭제 기능이 없음.**
- 따라서 기간 지정 삭제는 **자동삭제 전용 도구**로 따로 처리한다.

---

## 권장 구조

```
① FolderSync  : 폰 → 구글 드라이브  "업로드 전용"
                (원본 그대로 둠, 삭제 동기화 OFF → 드라이브 백업 영구 보존)
② 자동삭제     : 폰의 Recordings 폴더에서 'N개월 지난 파일'만 주기 삭제
```

### ⚠️ 필수 안전 설정 (데이터 보호)
1. FolderSync 폴더쌍의 **동기화 유형 = 로컬 → 원격 (업로드만)**
2. **"삭제 동기화 (Sync deletions)" = 끄기(OFF)**
   - 이래야 폰에서 원본을 지워도 **드라이브 백업이 삭제되지 않음**.
3. 자동삭제는 **반드시 ①번 백업이 끝난 뒤** 동작하도록 주기를 넉넉히(예: 백업은 즉시/매시간, 삭제는 매일 1회) 둔다.
4. 처음엔 **짧은 기간으로 테스트하지 말고**, 드라이브에 실제로 다 올라갔는지 눈으로 확인한 뒤 자동삭제를 켠다.

---

## ② 기간 기반 자동삭제 — 방법별

### 방법 A. 자동삭제 전용 앱 (가장 쉬움)
- Play 스토어에서 "auto delete files", "파일 자동 삭제", "Auto File Manager" 류 앱 검색.
- 설정: 대상 폴더 = `Recordings/Call`, `Recordings/Voice`, `Recordings/TPhoneCallRecords`
  / 규칙 = **"N일 지난 파일 삭제"** (예: 30일=1개월, 365일=12개월)
- 장점: 클릭 몇 번. 단점: 앱마다 신뢰성·광고 차이 → 평점·권한 확인 후 선택.

### 방법 B. MacroDroid / Tasker (자동화 앱)
개념:
- **트리거:** 매일 특정 시각(예: 새벽 4시)
- **액션:** 지정 폴더에서 **수정일이 N일 이전**인 파일을 찾아 삭제
- Tasker가 파일 나이 비교(루프 + 파일 수정시간 변수)에 더 적합. MacroDroid도 가능하나 파일 목록 순회 로직이 필요.
- 장점: 조건 세밀 제어(충전 중·Wi‑Fi 등). 단점: 초기 구성 다소 번거로움.

### 방법 C. Termux + 스크립트 (가장 정밀)
```sh
# 예: Recordings 하위에서 30일(약 1개월) 지난 녹음 파일 삭제
find /storage/emulated/0/Recordings/Call \
     /storage/emulated/0/Recordings/Voice \
     /storage/emulated/0/Recordings/TPhoneCallRecords \
     -type f -mtime +30 -delete
```
- `+30` = 30일, `+365` = 12개월. 기간은 숫자만 바꾸면 됨.
- Termux의 `termux-job-scheduler` 또는 cron으로 매일 실행 예약.
- 장점: 기간 지정이 가장 정확. 단점: 설치·권한(`termux-setup-storage`) 등 기술적.

---

## 기간 예시
| 원하는 보관 기간 | 일수 값 |
|---|---|
| 1개월 | 30 |
| 3개월 | 90 |
| 6개월 | 180 |
| 12개월 | 365 |

---

## 정리
- **기간 지정 자동삭제는 FolderSync 단독으로는 불가** → 별도 자동삭제 도구 조합.
- 핵심은 **FolderSync를 업로드 전용 + 삭제 동기화 OFF**로 두어 드라이브 백업을 지키는 것.
- 쉬움 → 자동삭제 앱 / 중간 → MacroDroid·Tasker / 정밀 → Termux 스크립트.
