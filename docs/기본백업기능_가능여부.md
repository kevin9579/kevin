# 갤럭시 기본 백업 기능으로 구글 드라이브 자동 업로드가 가능한가?

> **요약: 불가능합니다.** 갤럭시 기본 백업 기능만으로는
> "통화/에이닷/음성녹음 폴더"를 "구글 드라이브"에 "원하는 폴더 구조로 자동 업로드"할 수 없습니다.
> 자동으로 하려면 FolderSync(또는 Autosync) 같은 동기화 앱이 필요합니다.

## 기본 기능별 한계

| 기본 기능 | 저장 위치 | 녹음 폴더 자동 업로드 | 한계 |
|---|---|---|---|
| 삼성 클라우드 | 삼성 서버 | ❌ | 구글 드라이브로 가지 않음. 통화/음성 녹음 파일 백업이 잘 안 됨(보고 다수). 파일을 폴더로 직접 관리 불가 |
| 구글 백업 (설정>Google>백업) | 구글 | ❌ | 기기 복원용 데이터일 뿐, 녹음 파일을 드라이브 폴더로 열람 불가 |
| 구글 포토 | 구글 포토 | ❌ | 사진·동영상만. 음성(.m4a) 백업 안 됨 |
| 구글 드라이브 앱 | 구글 드라이브 | ⚠️ 수동만 | 폴더 자동 감시·업로드 기능 없음 |

**"구글 드라이브 + 특정 폴더 자동 + 사용자 지정 폴더 구조"** 세 조건을 동시에 만족하는 기본 기능은 없습니다.

## 기본 기능만 쓰는 현실적 대안

### 1) 구글 드라이브 앱 수동 업로드 (자동 아님)
1. `내 파일` 앱 → `내장 저장공간 / Recordings / Call` (또는 `Voice`, `TPhoneCallRecords`)
2. 파일 전체 선택 → **공유 → 드라이브에 저장**
3. 저장 위치를 `01.KEVIN_HP / 01.음성데이타 / Call` (해당 폴더)로 지정
- 새 녹음이 생길 때마다 **직접 반복**해야 함.

### 2) 삼성 클라우드 자동 백업 (구글 드라이브 아님)
- 삼성 계정 자동 백업은 **삼성 클라우드로만** 저장됨. 구글 드라이브로는 가지 않음.

## 자동을 원하면
- **FolderSync / Autosync** 설치가 사실상 유일한 자동화 방법.
- 설치·설정은 [README.md](../README.md) 참고. 한 번 설정하면 이후 자동.
