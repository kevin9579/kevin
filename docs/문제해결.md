# 문제 해결 / 자주 묻는 질문 (FAQ)

## Q1. 파일이 자동으로 안 올라가요.
1. **배터리 최적화 예외**를 했는지 확인하세요. (설정 > 배터리 > 백그라운드 사용 제한 → FolderSync **제한 없음**)
2. 폴더쌍의 **"변경 시 동기화/즉시 동기화(Instant sync)"** 가 켜져 있는지 확인.
3. **"Wi‑Fi에서만 동기화"** 를 켰다면, Wi‑Fi에 연결되어 있어야 올라갑니다. (이동 중에는 보류됨)
4. FolderSync에 **"모든 파일 접근" 권한**이 허용돼 있는지 확인. (설정 > 애플리케이션 > FolderSync > 권한)

## Q2. "권한이 없습니다 / 폴더를 읽을 수 없습니다" 오류
- FolderSync 첫 실행 시 **모든 파일 접근(All files access)** 권한을 거부하면 발생합니다.
- 설정 > 애플리케이션 > FolderSync > 권한 > **파일 및 미디어 / 모든 파일 접근 허용**.

## Q3. 에이닷 폴더만 업로드가 안 돼요.
- 에이닷 저장 경로가 바뀌었을 수 있습니다. [폴더경로.md](폴더경로.md)의 "에이닷 폴더를 못 찾을 때" 순서대로 실제 경로를 다시 확인하고, 폴더쌍의 **로컬 폴더**를 수정하세요.

## Q4. 휴대폰에서 녹음을 지우면 드라이브에서도 지워지나요?
- **아니요.** 동기화 유형을 **"로컬 → 원격 (업로드만)"** 으로 설정했다면, 휴대폰에서 파일을 지워도 드라이브 백업은 그대로 남습니다.
- 만약 양쪽을 똑같이 맞추는 "양방향" 이나 "미러" 로 잘못 설정하면 삭제가 전파될 수 있으니, **반드시 "로컬 → 원격"** 인지 확인하세요.

## Q5. 같은 파일이 중복 업로드되나요?
- FolderSync는 이미 올라간 파일은 다시 올리지 않습니다(변경된 파일만). 중복 걱정은 없습니다.

## Q6. 데이터 요금이 걱정돼요.
- 폴더쌍 옵션에서 **"Wi‑Fi에서만 동기화"** 를 켜 두세요. 모바일 데이터로는 올리지 않습니다.

## Q7. 구글 드라이브 용량이 부족해요.
- 무료 15GB를 다 쓰면 업로드가 멈춥니다. 드라이브에서 오래된 파일을 정리하거나, Google One 요금제로 용량을 늘리세요.

## Q8. 화면을 꺼두면 동기화가 느려요.
- 안드로이드 절전 때문입니다. 배터리 최적화 예외(README 5단계)와, 가능하면 **충전 중 + Wi‑Fi 연결** 상태에서 한 번씩 동기화되도록 예약을 함께 설정하면 누락이 줄어듭니다.
