# 녹음 폴더 경로 빠른 참조 (갤럭시 S24+ / One UI 6)

## 세 폴더의 기본 저장 위치

모두 **내 파일 > 내장 저장공간** 아래에 있습니다.

| 종류 | 경로 | 비고 |
|---|---|---|
| **전화 (삼성 통화녹음)** | `Recordings/Call` | 전화 앱 자동/수동 통화녹음 |
| **음성녹음 (삼성 음성 녹음기)** | `Recordings/Voice` | 음성 녹음기 앱 저장 위치 |
| **에이닷 전화 (A. 통화녹음)** | `Recordings/TPhoneCallRecords` | 앱 버전에 따라 다를 수 있음 ↓ |

> 전체 절대 경로로는:
> - `/storage/emulated/0/Recordings/Call`
> - `/storage/emulated/0/Recordings/Voice`
> - `/storage/emulated/0/Recordings/TPhoneCallRecords`

---

## 에이닷 폴더를 못 찾을 때

에이닷(A.) 앱은 버전·기기에 따라 저장 위치가 달라질 수 있습니다. 아래 순서로 확인하세요.

1. **내 파일** 앱에서 다음 후보 폴더를 차례로 확인:
   - `내장 저장공간 / Recordings / TPhoneCallRecords`  ← 가장 흔함
   - `내장 저장공간 / Music / TPhoneCallRecords`
   - `내장 저장공간 / mysounds`
2. **에이닷 앱 안에서 직접 확인:**
   - 에이닷 실행 → 우측 하단 **설정** → **통화 설정** → **통화녹음**
   - 여기서 녹음 파일 관리 화면을 통해 저장 위치를 알 수 있습니다.
3. **파일 검색으로 찾기:**
   - "내 파일" 앱 상단 **검색(돋보기)** 에서 `.m4a` 또는 `.amr` 로 검색
   - 통화녹음 파일이 들어 있는 폴더 이름을 확인한 뒤, 그 폴더를 FolderSync 로컬 폴더로 지정

---

## 파일 형식 참고

- 삼성 통화녹음 / 음성녹음: 보통 **`.m4a`**
- 에이닷 통화녹음: **`.m4a`** 또는 **`.amr`**

FolderSync에서 특정 형식만 올리고 싶다면, 폴더쌍의 **필터(Filters)** 에서 `*.m4a` 같은 규칙을 추가할 수 있습니다(선택 사항).
